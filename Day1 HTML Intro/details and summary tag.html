Semantic and Non Semantic Tags in HTML

Semantic and Non Semantic tags in HTML are used to show the content in different ways. Semantic tags or elements refers to an element which provides meanings to the web page rather than just presentation. Semantic tags clearly describe their meaning in a human- and machine-readable way.Examples of semantic elements are: header, footer, article, and section. Non-semantic elements tell nothing about its content. Examples of non-semantic elements are: div and span.
